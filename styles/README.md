# Site Style Examples

These CSS files are standalone visual themes for the site. Add one of them after `themes.css` in a page's `<head>`:

```html
<link rel="stylesheet" href="../themes.css" />
<link rel="stylesheet" href="../styles/rose-ember.css" />
```

Available styles:

- `rose-ember.css` — warm red and copper accents.
- `cyber-midnight.css` — blue-violet neon with sharper contrast.
- `forest.css` — green and moss tones.
- `ice-slate.css` — cool silver and cyan tones.

Use `themes.css` as the base theme. These files only override the shared color variables and selected UI surfaces.
